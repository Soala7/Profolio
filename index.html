01 / SYSTEMS

Gorgon VOS

A virtual operating system project evolving from a Python-based desktop environment into a real OS and virtualization architecture. The long-term system includes a bootloader, kernel, virtual memory, processes, drivers, userspace, applications, and a QEMU-based execution environment.

C C++ Assembly QEMU Linux Python
