Overview

Chess Game 2.0 is a complete chess application built with Python and Pygame. It features a modern graphical interface, AI opponent with adjustable difficulty, sound effects, and full chess rule enforcement using the python-chess library. The game supports both human vs AI and human vs human modes.

Implementation Details

1. Chess Engine (python-chess)

The game uses the python-chess library for all chess logic. This includes move generation, validation, board state management, and game over detection. This allows the project to focus on the UI and AI implementation.

2. AI Opponent

The AI uses negamax search with alpha-beta pruning. It evaluates positions using material balance, piece-square tables, and mobility. The search depth can be adjusted from 2 (Easy) to 6 (Expert) plies.

$ python ai_bot.py
AI Engine initialized with depth 4
Evaluation: material + positional + mobility
Search: negamax with alpha-beta pruning
Move ordering: captures > promotions > checks
Quiescence search enabled for tactical stability

3. Piece Rendering

The game supports both image-based and Unicode piece rendering. Images are loaded from the assets folder, with Unicode symbols as a fallback. This ensures the game works even without custom images.

4. Sound Engine

The sound engine plays contextual sounds for moves, captures, checks, promotions, and game events. Sounds are loaded from the assets folder with fallback to silence if files are missing.

5. Launcher

The launcher provides a clean interface for selecting the game mode (vs AI or vs Human) and AI difficulty. It uses a gradient background with a translucent panel for a modern feel.

Controls

Click "Play vs AI" or "Play vs Human"
Select AI difficulty (1-5) when prompted
Game:
Click piece → Select, Click square → Move
R: Reset game
H: Show game analysis
F: Flip board
S: Toggle sound
ESC: Quit
