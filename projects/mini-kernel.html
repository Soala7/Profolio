Overview

This is a small experimental 64-bit x86 kernel built from scratch in C and Assembly. The project follows the early stages of OS development: creating a bootable kernel, setting up the CPU for 64-bit long mode, configuring paging, and writing directly to VGA text memory.

This project is part of my learning process toward building Gorgon VOS.

How It Works

The kernel starts in 32-bit protected mode after being loaded by GRUB. The Assembly boot code then performs a series of steps to transition the CPU into 64-bit long mode:

GRUB — loads kernel into memory
↓
header.asm — Multiboot2 header
↓
main.asm — boot entry point
↓
1. Verify Multiboot2 environment
↓
2. Check for CPUID support
↓
3. Check for x86_64 long mode support
↓
4. Create initial page tables
↓
5. Enable PAE (Physical Address Extension)
↓
6. Enable long mode via EFER MSR
↓
7. Enable paging
↓
8. Load 64-bit GDT
↓
main64.asm — enter 64-bit mode
↓
main.c — C kernel entry point
↓
VGA Text Output — prints to screen

Implementation Details

1. Multiboot2 Header

The kernel starts with a Multiboot2 header that GRUB uses to identify and load the kernel. The header includes architecture flags and ensures the kernel is loaded at the correct memory address.

2. Boot Assembly

The main.asm file contains the 32-bit boot code that performs CPU capability checks and transitions to 64-bit mode. It uses the CPUID instruction to verify the CPU supports long mode and PAE.

3. Paging Setup

The boot code creates identity-mapped page tables that map the first 2MB of physical memory. This is sufficient for the kernel to run in 64-bit mode with paging enabled.

4. 64-bit Transition

The kernel enables PAE, sets the long mode bit in the EFER MSR, and enables paging. It then loads a 64-bit GDT and performs a far jump into the 64-bit code segment.

5. C Kernel Entry

The main.c file contains the C entry point for the kernel. It initializes the VGA text buffer and prints messages to the screen using the print.h interface.

6. VGA Text Output

The kernel writes directly to the VGA text buffer at 0xB8000. Each character is 2 bytes: the ASCII value and an attribute byte for color. The screen is configured as 80 columns × 25 rows.

Building

The project uses Docker to provide a controlled kernel-development environment. The container contains all the tools required to build the kernel.

$ git clone https://github.com/Soala7/Mini-Kernel
$ cd Mini-Kernel
$ docker build -t mini_kernel:latest buildenv
Building Docker image...
$ docker run -it --rm -v "$(pwd):/root/env" mini_kernel:latest
Entering build environment...
# make build-x86_64
Building kernel...
