Overview

This project implements a Deep Q-Learning (DQN) agent that learns to play the classic Snake game. The agent observes the game state, makes decisions using a neural network, and improves its performance through repeated gameplay. The project demonstrates key reinforcement learning concepts including experience replay, reward shaping, and neural network-based decision making.

How It Works

1. State Representation

The agent observes 16 features from the game state:

  • Danger straight ahead
  • Danger to the right
  • Danger to the left
  • Current direction (up, down, left, right)
  • Food position relative to snake head
  • Food distance
  • Body length
  • Tail position relative to head

2. Neural Network Architecture

The DQN uses a feedforward neural network with three hidden layers:

Input (16 features)
↓
Layer 1 (256 neurons + ReLU)
↓
Layer 2 (256 neurons + ReLU)
↓
Layer 3 (128 neurons + ReLU)
↓
Output (3 actions: straight, left, right)

3. Training Process

The agent learns through repeated episodes:

Initialize — set hyperparameters, load model
↓
For each episode — reset game state
↓
1. Get current state (16 features)
↓
2. Choose action (ε-greedy policy)
↓
3. Execute action, observe reward
↓
4. Store experience in replay memory
↓
5. Sample batch and train network
↓
6. Update target network periodically
↓
Save — checkpoint when new record achieved

Implementation Details

1. Agent (agent.py)

The agent implements the DQN training loop. It manages the exploration-exploitation tradeoff using an epsilon-greedy policy, stores experiences in replay memory, and orchestrates the training process.

2. Game Environment (snake.py)

The Snake game is built with Pygame. It provides the game state, handles movement, collision detection, and renders the game. The environment returns the current state, reward, and whether the game is done.

3. Neural Network (model.py)

The neural network is implemented in PyTorch. It consists of three linear layers with ReLU activations. The Q-learning trainer handles backpropagation, loss calculation, and network updates.

4. Training Visualization (helper.py)

The helper module uses Matplotlib to plot training metrics, including score progression and running average score, providing insight into the agent's learning progress.

Challenges

  • Designing effective state features for the agent
  • Tuning hyperparameters for stable learning
  • Handling the delayed reward problem in Snake
  • Implementing tail awareness to prevent self-collision
  • Optimizing training performance for faster learning

Limitations

  • Training can take hundreds of episodes to reach high scores
  • Agent may get stuck in local optima
  • No transfer learning — each environment requires retraining
  • Simple game environment — no obstacles or advanced mechanics
